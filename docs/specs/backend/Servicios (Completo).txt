# Servicios Backend - Ideaboard App

## AIService
Servicio para interactuar con modelos de IA (GLM-4.5)

### Métodos:
- `generateContent(blocks, format)`: 
  - Construye prompt estructurado
  - Envía a GLM-4.5
  - Retorna contenido generado
  
- `generateProjectSummary(projectName, files)`:
  - Genera resumen automático
  - Usa nombres de archivos como contexto

## StorageService
Servicio para manejo de archivos en la nube

### Métodos:
- `uploadFile(file)`: 
  - Sube a AWS S3/Google Cloud
  - Retorna URL pública
  
- `deleteFile(url)`: 
  - Elimina archivo de la nube
  
- `generateDownloadUrl(url)`: 
  - Genera URL temporal de descarga

## OCRService
Servicio para reconocimiento de texto

### Métodos:
- `extractText(imagePath)`:
  - Usa Tesseract.js (gratis)
  - O Google Cloud Vision (pago)
  - Retorna texto extraído

## AuthService
Servicio de autenticación

### Métodos:
- `hashPassword(password)`: 
  - Hashea con bcrypt
  
- `comparePassword(password, hash)`: 
  - Verifica contraseña
  
- `generateToken(user)`: 
  - Genera JWT
  
- `verifyToken(token)`: 
  - Verifica y decodifica JWT

## TemplateService
Servicio para manejo de plantillas

### Métodos:
- `createTemplate(userId, name, description, blocks, isPublic)`:
  - Crea nueva plantilla
  
- `applyTemplate(projectId, templateId)`:
  - Aplica plantilla a proyecto
  - Crea bloques basados en plantilla

## VersionService (Premium)
Servicio para control de versiones

### Métodos:
- `createVersion(projectId)`:
  - Crea instantánea del proyecto
  - Almacena como nueva versión
  
- `revertToVersion(projectId, versionId)`:
  - Restaura proyecto a versión anterior

## NotificationService
Servicio para notificaciones en tiempo real

### Métodos:
- `sendNotification(userId, message, type)`:
  - Usa WebSockets o Firebase Cloud Messaging
  - Envía notificación al usuario
