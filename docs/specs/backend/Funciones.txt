# Funciones - Ideaboard App

## Login/Registro
### Funciones Activas (Frontend)
- **A.1 Mostrar formulario login**
  - Componente: Login.tsx
  - Entrada: Ninguna
  - Salida: Formulario con email/contraseña
  - Relaciones: → B.1 Validar credenciales

- **A.2 Mostrar formulario registro**
  - Componente: Register.tsx
  - Entrada: Ninguna
  - Salida: Formulario con email/contraseña/nombre
  - Relaciones: → B.2 Crear usuario

### Funciones Backend
- **B.1 Validar credenciales**
  - Endpoint: POST /auth/login
  - Entrada: { email, password }
  - Salida: Token JWT + usuario
  - Relaciones: → B.3 Generar token JWT

- **B.2 Crear usuario**
  - Endpoint: POST /auth/register
  - Entrada: { email, password, name }
  - Salida: Usuario creado
  - Relaciones: → B.3 Generar token JWT

- **B.3 Generar token JWT**
  - Servicio: AuthService.generateToken
  - Entrada: Objeto usuario
  - Salida: Token JWT
  - Relaciones: ← B.1, B.2

### Funciones Backend
- **B.7 Obtener bloques**
  - Endpoint: GET /projects/:id/blocks
  - Entrada: ID proyecto
  - Salida: Lista bloques
  - Relaciones: → A.6 Mostrar bloques

- **B.8-B.11 Crear bloques (objetivo/contexto/restricción/formato)**
  - Endpoint: POST /blocks
  - Entrada: { type, content, projectId }
  - Salida: Bloque creado
  - Relaciones: ← A.7-A.10 Añadir bloques

- **B.12 Actualizar bloque**
  - Endpoint: PUT /blocks/:id
  - Entrada: { content }
  - Salida: Bloque actualizado
  - Relaciones: ← A.11 Editar bloque

- **B.13 Eliminar bloque de BD**
  - Endpoint: DELETE /blocks/:id
  - Entrada: ID bloque
  - Salida: Bloque eliminado
  - Relaciones: ← A.12 Eliminar bloque

- **B.14 Actualizar orden en BD**
  - Endpoint: PUT /blocks/reorder
  - Entrada: { projectId, blocks: [{id, order}] }
  - Salida: Orden actualizado
  - Relaciones: ← A.13 Reordenar bloques

- **B.15 Subir a almacenamiento**
  - Servicio: StorageService.uploadFile
  - Entrada: Archivo
  - Salida: URL archivo
  - Relaciones: ← A.14 Subir archivo

- **B.16 Procesar comando de voz**
  - Servicio: VoiceService.processCommand
  - Entrada: Audio
  - Salida: Texto reconocido
  - Relaciones: ← A.15 Activar voz

- **B.17 Construir prompt**
  - Servicio: AIService.generateContent
  - Entrada: Bloques + formato
  - Salida: Prompt estructurado
  - Relaciones: ← A.16 Generar contenido

- **B.18 Llamar a GLM-4.5**
  - Servicio: AIService.generateContent
  - Entrada: Prompt
  - Salida: Contenido generado
  - Relaciones: → A.17 Mostrar resultado

- **B.19 Obtener aiSummary**
  - Endpoint: GET /projects/:id/summary
  - Entrada: ID proyecto
  - Salida: Resumen
  - Relaciones: → A.18 Ver resumen

- **B.20 Actualizar userLabel**
  - Endpoint: PUT /projects/:id/label
  - Entrada: { label }
  - Salida: Etiqueta actualizada
  - Relaciones: ← A.19 Editar etiqueta

- **B.21 Aplicar plantilla**
  - Endpoint: POST /projects/:id/apply-template
  - Entrada: { templateId }
  - Salida: Bloques creados
  - Relaciones: ← A.20 Cambiar plantilla

- **B.22 Guardar como plantilla**
  - Endpoint: POST /templates
  - Entrada: { name, description, projectId, isPublic }
  - Salida: Plantilla creada
  - Relaciones: ← A.21 Guardar plantilla
